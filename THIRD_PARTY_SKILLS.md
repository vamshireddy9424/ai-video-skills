# Skills used alongside these (install from their own repos)

These are public and maintained upstream, so they are not copied here. Install with the
[`skills`](https://github.com/vercel-labs/skills) CLI:

```bash
npx skills add heygen-com/hyperframes    # hyperframes, -animation, -audio, -cli, -core, -creative, -keyframes, -registry, -studio, media-use
npx skills add firecrawl/skills          # firecrawl web research / scraping (needs a Firecrawl key)
npx skills add vercel-labs/skills        # find-skills
```

| Skill | Used for |
|---|---|
| hyperframes-* | HTML → video compositions, GSAP motion, audio mixing, keyframes |
| media-use | finding/generating music, SFX, voiceover |
| firecrawl-* | deep research for scripts (sources go in research.md) |
